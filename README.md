# CreatureCurios 后台按键器 v2.5.1

Windows 桌面小工具：绑定 `CreatureCurios` 窗口后，在后台循环投递 `A`
（可选空格拾取），
可选技能、喝药、疲劳检测和定时提醒；新增 **BOOS挂机** 分页，可录制地图路线、
BOSS 全过程，并一键在“刷怪”和“打BOSS”之间切换。

## 安装

要求 Windows + Python 3.10 及以上。

```bat
cd F:\jiaoben\3
pip install -r requirements.txt
```

手动安装：

```bat
pip install PySide6 pywin32 keyboard mouse rapidocr_onnxruntime
```

## 运行

```bat
python creature_curios_keyer.py
```

已打包版本：

```text
dist\CreatureCuriosKeyer.exe
```

> 如果游戏以管理员权限运行，本程序也要右键「以管理员身份运行」，
> 否则 `PostMessage` 可能被 Windows 权限隔离拦截。

## 分页一：基础挂机

- 绑定窗口、刷新窗口列表。
- 每轮间隔（默认 250ms，最小 50ms）。
- 循环动作：`A 按下 50ms → 松开`；
  - 勾选「A 后随机点击鼠标（加快攻速）」时，追加一次后台随机左键点击
    （在游戏客户区中间附近，不移动真实鼠标）；
  - 勾选「拾取物品（A 后按空格）」时，再追加 `空格按下 50ms → 松开`。
  - 两个都不勾选时只按 A。
- 可选技能 `1`（12 秒）/ `2`（6 秒）。
- 可选自动喝药 `Q`，默认间隔 60 秒。
- 可选疲劳检测：框选右下角会弹出疲劳提示的图标/按钮，每 30 秒点击并 OCR
  读取 `当前疲劳值:xxx/xxx`。
- **疲劳阈值 ±**：默认 800，可输入 600、500 等任意值（范围 50～1000）。
  - 基础页「辅助功能」里有输入框；
  - BOOS挂机页「一键打BOSS」区域也有一个相同的输入框，两边自动同步；
  - 基础页弹窗：低于 `-阈值` 或高于 `+阈值`；
  - 一键打BOSS：按 `阈值 - 20` 切换，例如阈值 600 → BOSS ≤ -580 / 刷怪 ≥ +580。
- 可选定时提醒：倒计时或指定时刻。
- 全局热键 `Ctrl + Alt + F8` 开始/停止；最小化/关闭窗口驻留托盘。

## 分页二：BOOS挂机

### 1. 点位设置（同地图）

- **设置打怪点 / 设置BOSS点**：点按钮后 3 秒内切到游戏地图，在地图上左键
  点击目标位置，程序记录该点的归一化坐标。
- **地图键 / 关闭键**：默认 `m` / `esc`，可改成你游戏实际使用的按键名。
- **回归打怪点 / 回归BOSS点**：自动执行

  ```text
  按地图键打开地图
  → 点击保存的点位
  → 按关闭键关闭地图
  ```

  这两个按钮用于**同一张地图**；跨地图请先手动换图。使用前请确保地图是关闭状态。

### 2. 流程录制 / 回放

三个可独立录制的步骤：

1. 打怪点 → BOSS点（路线）
2. BOSS 全过程（战斗操作）
3. BOSS点 → 打怪点（返回路线）

每一步都有：

- **录制**：3 秒后开始录制；切到游戏操作，完成后回本窗口点「停止录制」。
- **开始**：回放该步骤。回放时游戏会被切到前台并接管鼠标/键盘。
- **重新录制**：保留旧录制直到新录制成功；新录制为空或失败时不会覆盖旧录制。
- 录制内容包括鼠标移动、左/右/中键、滚轮、键盘按下/抬起。
- **录制过程中可以点「回归打怪点 / 回归BOSS点」**：程序会实际执行回归，
  并把地图键、点位点击、关闭键一起录入当前流程。请等 3 秒倒计时结束、
  录制真正开始后再点。
- 录制只在**游戏是前台窗口**且鼠标位于游戏窗口内时记录，避免把点击本程序
  或其它窗口的动作录进去。
- **分辨率自适应（新录制）**：鼠标事件直接保存为**游戏客户区归一化坐标**
  （`0~1`），回放时按当前客户区还原。窗口移动、改大小、`1366×768` /
  `1920×1080` 切换、换屏幕分辨率都不影响，不需要再依赖录制时的屏幕坐标。
- 录制时仍会保存客户区尺寸/位置/屏幕尺寸，但只用于界面显示和兼容旧数据，
  新录制的定位不再依赖这三个值。
- 旧版本录制没有归一化坐标，会按“当时全屏屏幕分辨率”做兼容缩放；界面上
  会显示「旧录制·按屏幕自适应」。如果旧录制仍不准，用新版本重录一次即可。
- 录制过程中不要移动游戏窗口或改窗口大小，否则同一段录制内部坐标会不一致。
- 录制会保存到：

  ```text
  %APPDATA%\CreatureCuriosKeyer\macros.json
  ```

  下次启动会自动加载，不需要重新录制。
- **回放请勿操作鼠标/键盘**，否则会打乱输入。

### 3. 一键打BOSS

启动前请确保：

1. 已绑定游戏窗口；
2. 已在基础页框选疲劳提示区域；
3. 已设置打怪点和BOSS点（地图键/关闭键可用）；
4. 三个流程都已录制；
5. 基础挂机没有在运行。

逻辑（阈值可在基础页或 BOOS挂机页输入，默认 ±800，触发时留 ±20 缓冲）：

```text
启动后先检测一次疲劳值
→ 疲劳 ≤ -(阈值-20)：
    1. 回归打怪点
    2. 执行“打怪点 → BOSS点”录制
    3. 执行 BOSS 全过程（强制喝药 Q）

每次 BOSS 全过程结束（从副本出来）：
    4. 回归BOSS点
    5. 检测疲劳
       - 仍然低（< +(阈值-20)）：回到第 3 步，继续打 BOSS
       - 已经高（≥ +(阈值-20)）：
           6. 执行“BOSS点 → 打怪点”录制
           7. 回到打怪点继续刷怪

刷怪期间每 30 秒检测一次疲劳
→ 检测到 ≤ -(阈值-20) 就停止刷怪，进入上面的 BOSS 流程
```

- 从打怪点去 BOSS 点前，先「回归打怪点」；
- 每次从 BOSS 副本出来，先「回归BOSS点」，再决定继续打 BOSS 还是回打怪点；
- 从 BOSS 点回打怪点前，也已经先「回归BOSS点」；
- 点位回归使用「地图键 → 点击点位 → 关闭键」，默认 `m` / `esc`。

例如：

- 阈值 800：BOSS ≤ -780，刷怪 ≥ +780
- 阈值 600：BOSS ≤ -580，刷怪 ≥ +580
- 阈值 500：BOSS ≤ -480，刷怪 ≥ +480

- 刷怪阶段是否喝药由「打怪时喝药 Q」复选框决定；
- 刷怪阶段是否按空格拾取由基础页「拾取物品（A 后按空格）」复选框决定；
- **BOSS 阶段强制喝药 Q**，喝药间隔沿用基础页的设置；
- BOSS 路线的两个录制步骤使用真实鼠标/键盘回放，因此会短暂把游戏切到前台；
- 刷怪阶段仍使用后台 `PostMessage`，你可以正常使用其它窗口；
- 检测疲劳时会短暂点击右下角提示区域并恢复鼠标/前台窗口。

### 4. 稳定BOSS（不录制）

BOOS 挂机页新增「使用稳定模式（不需要三个录制）」复选框，默认**不勾选**。
不勾选时仍使用原来的三个录制（已支持分辨率自适应）；勾选后，上面的
「一键打BOSS」不再依赖 `to_boss` / `boss_fight` / `to_farm`，而是：

```text
地图键 → 点击 BOSS 点 → 关闭地图
→ 游戏自动寻路到副本入口
→ OCR 找入口弹窗关键词并点击（找不到时用预设按钮点）
→ 进入副本，固定战斗 N 秒（强制喝药 Q）
→ OCR 找退出弹窗关键词并点击（找不到时用预设按钮点）
→ 检测疲劳：仍低就继续打 BOSS，高了就回打怪点刷怪
```

- **BOSS点**：设置成地图上的副本入口，不是副本里面的位置；
- **打怪点**：照旧；
- **入口/退出弹窗**：优先 OCR 关键词；建议同时设置「入口按钮 / 退出按钮」的
  固定点击点作为兜底。设置方法：先在游戏里打开弹窗，再回本程序点
  「设置入口按钮」/「设置退出按钮」，在截图上框住按钮即可；
- **稳定性**：所有点击使用客户区归一化坐标，窗口移动、1366×768 / 1920×1080
  切换都不影响；不再回放整段鼠标轨迹；
- **BOSS战**：和刷怪同一套按键循环，`A / 空格 / 技能 / 喝药`，开始战斗时会
  立即喝一次 Q；固定打 `BOSS战` 秒数，默认 6 秒；
- **不会死**：按你的设定，只打能秒的怪，不做死亡/复活处理；
- **单次测试**：「稳定模式 单次测试」只跑一次：地图→入口→战斗→退出，不接
  疲劳循环，适合先验证弹窗和按钮；
- **日志**：`%APPDATA%\CreatureCuriosKeyer\stable_boss.log`；识别失败会把
  当前游戏画面保存到同目录 `stable_fail_*.png`，方便定位。

如果要调整等待时间/关键词：

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 寻路/入口等待 | 30 秒 | 关闭地图后，等自动寻路并识别入口弹窗的最长时间 |
| BOSS战 | 6 秒 | 进入副本后自动打多久 |
| 退出弹窗等待 | 12 秒 | BOSS 打完后，等退出弹窗的最长时间 |
| 加载等待 | 4 秒 | 进/出副本后的加载等待 |
| 回打怪点等待 | 15 秒 | 点打怪点后等自动寻路的时间 |
| 入口关键词 | 进入,挑战,确认 | OCR 在入口弹窗里找的词 |
| 退出关键词 | 离开,退出,确认 | OCR 在退出弹窗里找的词 |

## 实现要点

- 后台按键：`win32api.PostMessage` + `WM_KEYDOWN/WM_KEYUP`，扫描码和
  `lParam` 按 Windows 规范构造。
- Unity 后台焦点补偿：补发
  `WM_ACTIVATEAPP / WM_NCACTIVATE / WM_ACTIVATE / WM_SETFOCUS`，
  不调用 `SetForegroundWindow`。
- 宏录制：`mouse` 全局钩子 + `keyboard` 全局钩子，按事件时间线保存 JSON。
- 宏回放：`SendInput`（鼠标绝对坐标） + `keyboard` 按键，按录制时间线回放；
  结束时释放所有仍按下的键/鼠标键。
- 疲劳检测：点击用户框选的提示区域 → `PrintWindow` 后台截图 →
  恢复鼠标/前台窗口 → RapidOCR 读取 `当前疲劳值:xxx/xxx`。
- 提醒弹窗：`WS_EX_NOACTIVATE`，置顶但不抢焦点。
- 全局热键：`keyboard.add_hotkey("ctrl+alt+f8", ...)`。

## 常见问题

### 录制为空 / 录制不到鼠标

- 录制开始前请让游戏处于前台；
- 只在游戏窗口内操作；
- 3 秒倒计时结束后才开始记录；
- 录制中不要点到本程序窗口；
- 录完回本窗口点「停止录制」。

### BOSS 战录制后不攻击 / 连点丢失

旧版本录制时，`mouse` 库会把快速连点的第二次按下标记为 `double` 事件，
旧逻辑只接受 `down` / `up`，导致连点的按下动作被丢弃，回放时看起来就像
BOSS 战没有攻击。新版本已把 `double` 还原为按下，并忽略录制开始前遗留的
孤立 `up`。

如果旧版本录制的 BOSS 流程已经缺失连点，需要重新录制「BOSS 全过程」，
建议三个流程都用新版本重录一遍。

### 回归点位不对

- 确认「地图键」「关闭键」与游戏一致；
- 点位是在哪张地图设置的，就在哪张地图使用；
- 如果窗口分辨率变化，点位会按比例缩放，偏差大时重新设置。

### 一键打BOSS不启动

逐项检查：

- 是否绑定了游戏窗口；
- 是否在基础页框选了疲劳提示区域；
- 三个流程是否都已录制；
- 基础挂机是否已停止；
- 游戏是否最小化。

### 回放时鼠标/键盘被接管

这是录制回放的设计：鼠标操作需要真实前台输入。回放结束后会恢复鼠标位置和
之前的前台窗口。回放过程中请不要操作鼠标键盘。

### 疲劳检测显示“识别失败”

- 确认框选的是右下角**会弹出疲劳提示的图标/按钮**；
- 点「测试检测」看游戏是否弹出 `当前疲劳值:xxx/xxx`；
- 第一次识别需要加载 OCR 模型，可能多等 1～3 秒。

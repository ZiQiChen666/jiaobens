# CreatureCurios 后台按键器 v2.5.1

Windows 桌面小工具：绑定 `CreatureCurios` 窗口后，在后台循环投递 `A`
（可选空格拾取），可选技能、喝药、疲劳检测和定时提醒。

包含 **基础挂机 / BOOS挂机 / 多开挂机** 三个分页；多开挂机最多同时管理 4 个游戏窗口。
原来的「点位设置」「一键打BOSS」「稳定BOSS」已移除。

## 安装

要求 Windows + Python 3.10 及以上。

```bat
cd F:\jiaoben\3
pip install -r requirements.txt
```

手动安装：

```bat
pip install PySide6 pywin32 keyboard mouse rapidocr_onnxruntime
```

## 运行

```bat
python creature_curios_keyer.py
```

已打包版本：

```text
dist\CreatureCuriosKeyer.exe
```

> 如果游戏以管理员权限运行，本程序也要右键「以管理员身份运行」，
> 否则 `PostMessage` 可能被 Windows 权限隔离拦截。

## 分页一：基础挂机

- 绑定窗口、刷新窗口列表。
- 每轮间隔（默认 250ms，最小 50ms）。
- 循环动作：`A 按下 50ms → 松开`；
  - 勾选「拾取物品（A 后按空格）」时，再追加 `空格按下 50ms → 松开`；
  - 不勾选时只按 A（原来的“A 后随机点地板”已移除）。
- 可选技能 `1`（12 秒）/ `2`（6 秒）。
- 可选自动喝药 `Q`，默认间隔 60 秒。
- 可选疲劳检测：框选右下角会弹出疲劳提示的图标/按钮，每 30 秒点击并 OCR
  读取 `当前疲劳值:xxx/xxx`。
- **疲劳阈值 ±**：默认 800，可输入 600、500 等任意值（范围 50～1000）；
  低于 `-阈值` 或高于 `+阈值` 时弹窗。
- 可选定时提醒：倒计时或指定时刻。
- 全局热键 `Ctrl + Alt + F8` 开始/停止；最小化/关闭窗口驻留托盘。

## 分页二：BOOS挂机

### 1 · 地图按键 / 路线

- **地图键 / 关闭键**：默认 `m` / `esc`，可改成游戏实际使用的按键名。
  下面的地图寻路和路径执行都会使用这两个键。
- **录制 / 管理打怪路线（窗口相对坐标）**：打开路线编辑器。

### 2 · 地图标注寻路（人工坐标）

完全不依赖 OCR 识别地图文字。坐标体系：

```text
窗口客户区左上角 = 窗口零点
地图左上角零点/右下角范围 = 在截图上人工标定
打怪点/BOSS点 = 相对地图零点的地图内坐标
运行时：窗口零点 + 地图范围 + 地图内坐标
```

标注/编辑地图：

1. 游戏里按 `M` 打开地图，保持打开；
2. 主程序点「标注 / 编辑地图（人工）」；
3. 点「标定地图零点/范围」：在截图上点地图左上角零点，再点右下角；
4. 填目标名称/类型 →「手动添加目标（点坐标）」→ 在截图上点真正入口；
5. 重复添加打怪点/BOSS点；
6. 点「保存地图」。

修改已保存地图：

1. 在顶部「已保存」下拉框选地图 →「载入已保存地图」；
2. 可以改名称/类型、删除目标、**重新点选选中目标**；
3. 再点「保存地图」覆盖保存。

保存位置：

```text
%APPDATA%\CreatureCuriosKeyer\maps.json
```

测试：

```text
选择地图 → 选择目标 → 设“寻路等待” → 点“测试前往目标”
```

程序会：`M 打开地图 → 等待 → 点击人工记录的地图坐标 → Esc → 等待自动寻路`。

点击后会检查是否真的开始寻路：

- 如果检测到「该地点无法到达 / 无法前往」等提示，会自动关闭提示并再点一次；
- 如果点击后画面一直没有变化（人物没动），也会自动再点一次；
- 最多重试 1 次，避免死循环。

- 只移动游戏窗口没问题；
- 如果改窗口大小或地图缩放，需重新标定地图范围/重新点选目标；
- 日志：`%APPDATA%\CreatureCuriosKeyer\map_travel.log`。

### 3 · 路径执行（地图标注）

路径步骤：

```text
地图 + 已标注入口 + 等待秒数
```

编辑路径：

1. 点「编辑路径」；
2. 填路径名；
3. 选地图/目标；
4. 填等待秒数；
5. 添加步骤，可上移/下移/删除；
6. 保存。

保存位置：

```text
%APPDATA%\CreatureCuriosKeyer\paths.json
```

执行路径：

1. 选择路径 →「执行路径」；
2. 每一步：
   - 执行路径前先按一次「骑乘键」（默认 `F`，可在第 1 组里改/留空）；
   - **不再用 OCR 识别地图名**，直接用步骤里选的地图标注点；
   - 按 `M` 打开地图后，**地图一直保持打开**；
   - 点击该地图里人工标注的入口；
   - 在地图上等待：
     - 检测到**蓝色人物箭头到达标定点位** → 认为已到达；
     - 或检测到黑屏/白屏/硬切等**场景切换** → 认为已进入新地图；
   - 没检测到就再点一次，仍没检测到则报错停止；
3. 场景切换后地图会关闭，下一步会自动重新按 `M` 打开；
   如果没有切换，后续步骤直接在已打开的地图上继续点。

日志：

```text
%APPDATA%\CreatureCuriosKeyer\path_run.log
```

> 日志里会输出 `场景检测：亮度 xx，变化 x.xxx`，如果识别不准，
> 可据此调整 `map_labels.py` 顶部的 `SCENE_*` 和 `NO_MOVE_DIFF_RATIO`。

### 4 · 副本整段录制 / 回放

不做任何 BOSS 血量/击败/拾取识别，只靠“整段录制”和“标记点”。

录制：

1. 先让角色站在固定起点（例如副本门口 / 打怪点）；
2. 点「开始录制」，3 秒内切到游戏；
3. 完整操作一遍：进副本 → 打 BOSS → 拾取掉落 → 退出副本；
4. 操作完切回本窗口点「停止录制」（也可以按 `Ctrl + Alt + F8` 停止）；
5. 给这段录制起个名字保存。

回放：

- 「试放一次」：只回放一遍，用来验证；
- 「开始副本」：按「重复」次数循环回放，0 = 无限循环；
- 「间隔」：两次回放之间等待的秒数；
- 「速度」：50%～200%；
- 「回放时鼠标被操作自动暂停」：默认勾选；回放中如果检测到你移动/点击鼠标，
  时间线会暂停，鼠标停止操作 0.6 秒后自动继续，避免脚本被鼠标打乱；
- 回放时游戏会切到前台，请勿操作鼠标键盘；结束后自动恢复原前台窗口。

录制保存位置：

```text
%APPDATA%\CreatureCuriosKeyer\records.json
```

> 录制只记录游戏窗口在前台时、鼠标在游戏窗口内的操作。
> 换分辨率/窗口大小也能回放，鼠标坐标按客户区归一化保存。

### 5 · 组合挂机（路径 + 副本录制）

把“路径”和“副本整段录制”组合成一个有名字的挂机方案：

- 新建组合：填名称，选择一条路径、一段副本录制；
- 路径或录制可以只选一个；
- 设置重复次数（0 = 无限循环）、每轮间隔、录制回放速度；
- 「编辑/重命名」可以改组合名、换路径/录制；
- 选择组合 →「开始组合」即可挂机。

每轮执行顺序：

```text
执行路径（走到副本入口）
→ 回放副本整段录制（进副本/打BOSS/拾取/退出）
→ 等待间隔
→ 下一轮
```

保存位置：

```text
%APPDATA%\CreatureCuriosKeyer\combos.json
```

> 路径或录制被删除/改名后，组合会提示“引用的路径/录制不存在”，
> 打开「编辑/重命名」重新选择即可。

### 6 · 疲劳循环（挂机 ↔ 录制）

最简单的循环：

```text
在打怪点挂机打怪
→ 每隔 N 秒检测疲劳
→ 疲劳 < -阈值：停止打怪，回放 BOSS 整段录制
→ 录制播放完：自动恢复打怪
→ 继续每隔 N 秒检测
```

- 只需要选择一段 **BOSS 整段录制**；
- 本组直接有「录制新脚本 / 试放 / 删除录制」按钮，不用回第 4 组；
- 录制里要包含：去 BOSS、进副本、打 BOSS、拾取、退出、回打怪点的全部操作；
- 不需要选路径、不需要点 BOSS 点、不需要 OCR 识别地图；
- 疲劳阈值默认 800，可在本组里直接改；
- 检查间隔默认 30 秒；
- 如果检测失败，会继续打怪并在下一次继续检测；
- 点「停止疲劳循环」或 `Ctrl+Alt+F8` 随时停止。

### 打怪路线编辑器

BOOS 页「1 · 地图按键 / 路线」里有按钮：

```text
录制 / 管理打怪路线（窗口相对坐标）
```

点开后是同一个 exe 内的路线编辑器，不是单独程序。所有坐标都以
**游戏窗口客户区左上角为 0,0**，保存为窗口内相对坐标，窗口移动/改大小不影响。

录制一条路线：

1. 填路线名、地图名；选择路径在「游戏世界」还是「地图界面」；
2. 切到游戏打开地图，按 **F8**，点击一次地图入口；
3. 关闭地图（如果是游戏世界路径），按 **F9** 开始连续记录点击，按顺序点路径点，按 **F10** 停止；
4. 回到编辑器，给每一步填「等待(秒)」和「说明」；
5. 需要开门/按 F 就用「添加按键」，需要等加载就用「添加等待」；
6. 点「保存路线」。

保存位置：

```text
%APPDATA%\CreatureCuriosKeyer\routes.json
```

编辑器只记录点击，不会自动操作游戏。

## 分页三：多开挂机

最多同时挂 4 个游戏窗口，每个窗口独立执行：

```text
打怪 → 定时检测疲劳 → 疲劳 < -阈值 → 回放 BOSS 录制 → 播完恢复打怪
```

### 设置

1. 先把 4 个游戏客户端都打开；
2. 到「多开挂机」页点「刷新窗口」；
3. 程序会自动把找到的窗口分配到 4 个槽位，也可以手动改；
4. 每个槽位分别选择自己的 **BOSS 整段录制**；
5. 设置疲劳阈值、检查间隔；
6. 点每个窗口的「开始」，或直接「全部开始」。

### 说明

- 每个窗口可以分别选择不同的 BOSS 录制；
- 4 个窗口共用疲劳阈值和检查间隔；
- **前台操作会排队**：录制回放、疲劳检测点击同一时间只允许一个窗口执行；
  其它窗口即使疲劳值到了，也会显示“等待其他窗口完成前台操作…”，
  排队等前一个窗口播完再开始；
- 每个窗口自己的后台打怪不受影响，可以继续打怪；
- 打怪参数沿用「基础挂机」页的 A / 空格 / 技能 / 喝药；
- 每个槽位有自己的打怪线程、疲劳检测和录制回放，互不影响；
- 同一个游戏窗口不能同时被两个槽位使用；
- 多开运行时，单窗口的基础挂机/路径/副本/疲劳循环会禁用；
- 关闭游戏窗口后，对应槽位会自动停止；
- 录制里要包含去 BOSS、进副本、打 BOSS、拾取、退出、回打怪点的全部操作。

## 实现要点

- 后台按键：`win32api.PostMessage` + `WM_KEYDOWN/WM_KEYUP`，扫描码和
  `lParam` 按 Windows 规范构造。
- Unity 后台焦点补偿：补发
  `WM_ACTIVATEAPP / WM_NCACTIVATE / WM_ACTIVATE / WM_SETFOCUS`，
  不调用 `SetForegroundWindow`。
- 地图寻路 / 路径执行：前台真实鼠标点击，坐标按客户区归一化换算。
- 地图切换：不再 OCR 识别地图名，改为检测黑屏/白屏/硬切等场景切换动画；
  切换后画面稳定即认为进入下一张地图。
- 疲劳检测：点击用户框选的提示区域 → `PrintWindow` 后台截图 →
  恢复鼠标/前台窗口 → RapidOCR 读取 `当前疲劳值:xxx/xxx`。
- 提醒弹窗：`WS_EX_NOACTIVATE`，置顶但不抢焦点。
- 全局热键：`keyboard.add_hotkey("ctrl+alt+f8", ...)`。

## 常见问题

### 路径执行失败 / 没有切换到新地图

- 确认路径里的地图名和地图标注里保存的名字一致；
- 地图标注范围或地图缩放变化后，重新标定/重新点选目标；
- 查看 `path_run.log` 里的 `场景检测：亮度 xx，变化 x.xxx`：
  - 如果切换地图时亮度没有明显变化，也不是硬切，需要调低
    `map_labels.py` 里的 `SCENE_DARK_BRIGHTNESS` / `SCENE_BIG_DIFF`；
  - 如果人物卡住却被当成“已移动”，调高 `NO_MOVE_DIFF_RATIO`；
- 日志和失败截图都在 `%APPDATA%\CreatureCuriosKeyer` 下。

### 疲劳检测显示“识别失败”

- 确认框选的是右下角**会弹出疲劳提示的图标/按钮**；
- 点「测试检测」看游戏是否弹出 `当前疲劳值:xxx/xxx`；
- 第一次识别需要加载 OCR 模型，可能多等 1～3 秒。
